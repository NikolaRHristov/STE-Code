# Translation Grid

Per-locale worker assignments for discovery-based translation scaffolding.

**Source:** `.agents/references/translation-grid.md`

3 workers per discovery target × 3 locales each:
- W1: zh-CN, ja, ko
- W2: es, fr, de
- W3: pt-BR, ru, ar

10 discovery targets → 30 workers → 10 batches.
