# Agent Development

1. Create `.agents/agent/agent-N-role.md` with: Identity, Skills, Architecture, Poll System, Worker Template, Verification, START NOW
2. Create `.agents/skills/<name>/SKILL.md` with YAML frontmatter
3. Add to `.agents/AGENTS.md`
4. Test with single worker before full batches
5. Commit: `feat(agent): Add Agent #N`

See [Contributing → README](README.md) for full template.
