# Adding Rules

1. Identify a documentation pattern not covered by existing rules
2. Write the rule: original STE text → code-domain rewrite → example pairs
3. Add to `ste-code/adapted/a-secN-ruleX.Y.md`
4. Add YAML frontmatter to `SCE/core/rules/rule-X.Y.md`
5. Update benchmarks if testable
6. Commit: `feat(rules): Add rule X.Y`

See [Contributing → README](README.md) for full guidelines.
