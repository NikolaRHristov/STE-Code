# Orchestration Protocol

Single-session protocol for managing all pipeline phases from one Hermes session.

## Launch Loop

```
PER BATCH (3 workers):
  1. Pick next 3 workers from tracker
  2. Launch: python3 .agents/tools/telemetry-worker.py <id> <prompt> --output <file>
     (background=true, notify_on_complete=true)
  3. Wait for all 3 → verify telemetry shows PASS
  4. Flip [ ] → [x] in FINAL-PASS-TRACKER.md
  5. git add -A && git gcommit-hermes "phase:<letter> batch:<N>"
  6. Push every 3 batches
```

## Rules

- **Never launch more than 3 at once.** Memory and API rate limits.
- **Never skip verification.** Check telemetry file exists and `self_healing.status == "PASS"`.
- **Never advance phase until all workers pass.** Every [ ] must become [x].
- **Commit after every batch.** `git gcommit-hermes` with phase + batch number.

## Self-Audit

After each phase:
1. Launch a review worker: `hermes -z "Quality review: audit all output from Phase <letter>..." -m deepseek-v4-pro --yolo`
2. Read findings
3. Fix all issues before advancing
4. Commit fixes

## Recovery

If a batch fails:
1. Read `RECOVERY-NEEDED/<worker-id>.md` (auto-generated by telemetry worker)
2. Understand the failure mode
3. Re-launch with narrowed scope (split the task, smaller prompt)
4. Never skip — every failed batch must be re-run until PASS
