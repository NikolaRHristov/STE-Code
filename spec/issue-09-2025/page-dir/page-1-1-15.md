**ASD-STE100 Simplified Technical English** 


##### <u>Words that are not approved but that can be technical verbs</u> 

The dictionary includes some words that, although not approved, can be technical verbs if you can put them in the specified categories. 

##### **Examples:** 

<mark>STE: Enter your password.</mark> (“Enter” is a technical verb, category 2 a), computer processes and applications, input and output processes.) _<mark>Non-STE: Do not enter the engine test area without approval.</mark>_ <mark>(“Enter” is not permitted when it is in a different context.) STE: Do not go into the engine test area without approval. STE: If the tower does not respond, use a different channel.</mark> (“Respond” is a technical verb, category 3 d), instructions and information for applicable subject fields, navigation.) _<mark>Non-STE: If the instrument fails to respond, do a test.</mark>_ <mark>(“Respond” is not permitted when it is in a different context.) STE: If the instrument does not operate correctly, do a test.</mark> 

#### **Rule 1.13 Do not use technical verbs as nouns.** 

In English, words that look the same do not always have the same function in a sentence. Use technical verbs only as verbs, not as nouns. 

##### **Example:** 

_<mark>Non-STE: Give the hole 0.20-inch ream.</mark>_ <mark>STE: Ream the hole to a 0.20-inch dimension.</mark> 

<mark>But you can use the past participle form of technical verbs as adjectives.</mark> 

##### **Example:** 

<mark>STE: Lubricate the reamed hole.</mark> (The adjective “reamed” is the past participle form of the technical verb “ream.” “Reamed hole” is a technical noun.) 

##### <u>Words that can be technical verbs and technical nouns</u> 

In some contexts, the same word can be a technical verb and a technical noun. This condition occurs when you can put this word in a technical verb category (rule 1.12) and in a technical noun category (rule 1.5). 

##### **Examples:** 

<mark>STE: Make sure that the plate is not damaged. (“Plate” is a technical noun, category 1, official parts information.)</mark>
