# Category Mapping: STE → STE-Code

## 19 Technical Code Noun Categories (adapted from ASD-STE100's 22)

| # | Original STE Category | STE-Code Category | Description |
|---|----------------------|-------------------|-------------|
| 1 | Official parts information | Language keywords and reserved words | `if`, `else`, `return`, `class`, `async`, `await`, `import`, `export` |
| 2 | Vehicles, machines, locations | Frameworks and runtimes | `React`, `Node.js`, `Docker`, `Kubernetes`, `PostgreSQL`, `Redis` |
| 3 | Tools and support equipment | Development tools and build systems | `webpack`, `esbuild`, `prettier`, `eslint`, `git`, `npm`, `cargo` |
| 4 | Materials and consumables | Dependencies and packages | `lodash`, `express`, `axios`, `pytest`, `serde`, `tokio` |
| 5 | Facilities and infrastructure | Deployment targets and environments | `staging`, `production`, `AWS`, `Vercel`, `Cloudflare`, `localhost` |
| 6 | Systems and components | Modules, classes, and components | `UserService`, `AuthModule`, `PaymentGateway`, `EventBus` |
| 7 | Mathematical/scientific terms | Algorithmic and computational terms | `hash`, `sort`, `bfs`, `dfs`, `O(n)`, `tree`, `graph`, `cache` |
| 8 | Navigation terms | Routing, pathing, and traversal | `/api/users`, `useNavigate`, `Router`, `middleware`, `redirect` |
| 9 | Numbers/units/time | Data sizes, time units, numeric formats | `500ms`, `2GB`, `200 OK`, `404`, `64-bit`, `UTC`, `epoch` |
| 10 | Quoted text | String literals, error messages, log text | `"connection refused"`, `Error: timeout`, `console.log(...)` |
| 11 | Persons/groups/organizations | Roles, teams, and services | `admin`, `moderator`, `OAuth provider`, `CI pipeline`, `CDN` |
| 12 | Parts of the body | UI/UX and accessibility terms | `button`, `modal`, `aria-label`, `focus`, `viewport`, `breakpoint` |
| 13 | Personal effects | Configuration and preferences | `.env`, `.gitignore`, `tsconfig.json`, `settings`, `profile` |
| 14 | Medical terms | Error states and diagnostics | `NullPointerException`, `500 Internal Server`, `race condition`, `deadlock` |
| 15 | Official documents | Specification files and configs | `package.json`, `Dockerfile`, `openapi.yaml`, `Makefile`, `README` |
| 16 | Environmental conditions | Runtime conditions and states | `cold start`, `warm cache`, `idle`, `under load`, `degraded` |
| 17 | Colors | Terminal colors and syntax highlighting | `red`, `green`, `cyan`, `magenta`, `bold`, `dim`, `256-color` |
| 18 | Damage terms | Bug, defect, and failure taxonomy | `crash`, `memory leak`, `race condition`, `XSS`, `SQL injection` |
| 19 | IT and telephony | Network, protocol, and API terms | `HTTP/2`, `WebSocket`, `gRPC`, `TLS`, `DNS`, `CDN`, `load balancer` |

## Categories 20–22 (merged into existing categories)
- Category 20 (Civil/military operations) → merged into Category 5 (Deployment)
- Category 21 (Law and regulations) → merged into Category 15 (Specification files)
- Category 22 (Animals, plants, life forms) → not applicable to code domain
