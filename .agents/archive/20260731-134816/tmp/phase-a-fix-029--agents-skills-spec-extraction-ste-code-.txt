- Use imperative mood for instructions
- Max 20 words per procedural sentence, 25 for descriptive
- One instruction per step
- BREAKING: before destructive changes
- DEPRECATED: before removed features
- NOTE: for important non-safety information

## Anti-Patterns
- Do not nest clauses deeper than 2 levels
- Do not use semicolons
- Do not use contractions (don't → do not)
- Do not omit articles (the, a, an)
- Do not use "-ing" forms as main verbs in procedures

### Rule 1: ZERO CONTENT LOSS
Every word, every number, every example, every table cell from the original
extraction MUST appear in the refined output. Format only — never delete.

### Rule 2: STANDARDIZED HEADINGS
```
# Page N of M          ← Every file starts with this

### Rule 3: TABLE FORMATTING
All tables MUST use clean markdown:
```markdown

|----------|----------|----------|
| Cell 1   | Cell 2   | Cell 3   |
```
- Align columns consistently
- Escape pipe characters inside cells: `\|`
- Merge split cells where the PDF layout broke them

```markdown
