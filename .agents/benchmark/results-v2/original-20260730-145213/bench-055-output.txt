**STE-CODE COMPLIANT DOCUMENTATION:**

# JSON Error Response Schema

This schema tells a REST API client about an error that occurred during a request.

## Fields

**`code`** (string) — An identifier for the type of error. The client can use this code to find the error in its documentation.

**`message`** (string) — A short text that tells what the error is. This text is safe to show to an end user.

**`detail`** (string or array) — More information about the error. This text can include technical data that helps a developer correct the problem.

**`help`** (string) — A text that tells the user or developer how to correct the error.

## Example

```json
{
  "code": "INVALID_INPUT",
  "message": "The request data is not correct.",
  "detail": "The email field must include a correct email address.",
  "help": "Send the request again with a correct email address in the email field."
}
```
