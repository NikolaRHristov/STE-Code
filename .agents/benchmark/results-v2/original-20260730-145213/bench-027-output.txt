Now I have all the STE-Code rules. Let me analyze the text systematically.

Input text to check:
```
## 3.0.0 — The old API was removed. Use the new one instead.
```

Violations found:

1. **Rule 3.2 (Active Voice)** — "The old API was removed" is passive voice. STE-Code requires active voice in all writing. The agent (the version/release) should perform the action.

2. **Rule GR-3 (Pronouns)** — "Use the new one instead" uses the pronoun "one" whose referent ("API") is clear from the preceding sentence, but the pronoun adds no value. Repeating the noun is clearer and follows the rule's spirit of unambiguous referents.

3. **Descriptive heading** (CONTRIBUTING.md line 195) — "3.0.0" alone is not descriptive. Section titles must describe their content.

4. **"instead" is filler** — it adds no information. STE-Code prefers concise sentences.

Corrected text:

```
## Version 3.0.0 — This version removes the old API. Use the new API.
```
