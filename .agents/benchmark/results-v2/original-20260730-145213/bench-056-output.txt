## Installation

Install Python 3.10 or a later version.

Install the tool with this command:

    pip install ste-code-checker

Make a configuration file in your home directory:

    mkdir -p ~/.ste-code-checker
    touch ~/.ste-code-checker/config.yaml

Set the project path and other options in the configuration file.

Run this command to make sure the installation is correct:

    ste-code-checker --version
