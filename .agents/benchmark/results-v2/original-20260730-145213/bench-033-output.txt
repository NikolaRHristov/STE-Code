### POST /api/users

Creates a new user.

**Request** — `Content-Type: application/json`

| Field      | Type   | Required | Description                                    |
|------------|--------|----------|------------------------------------------------|
| `username` | string | yes      | Unique username for the new user.              |
| `email`    | string | yes      | Email address of the user. Must be unique.     |
| `password` | string | yes      | Plaintext password. Stored as a bcrypt hash.   |

**Response** `201 Created` — `Location: /api/users/{id}`

```json
{
  "id": "usr_a1b2c3",
  "username": "alice",
  "email": "alice@example.com",
  "created_at": "2026-07-30T12:00:00Z"
}
```
