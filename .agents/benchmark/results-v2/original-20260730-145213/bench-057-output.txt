## Usage

To format a source file, run the `format` command with the file path.

**Example:**

```
$ format src/main.py
```

The command reads the file. The command applies the formatting rules. The command writes the result to the same file.

**Output:**

```
Formatting src/main.py... done
1 file formatted, 0 files unchanged
```

If the file already has the correct format, the tool shows this message:

```
Formatting src/main.py... unchanged
0 files formatted, 1 file unchanged
```

To check the format without writing changes, use the `--check` option:

```
$ format --check src/main.py
```

If the file is not formatted, the command shows the necessary changes. The command also exits with a non-zero exit code.
