# Corrected API Documentation

## Read User Profile

### Endpoint

```
read /api/users/:id
```

### Purpose
This endpoint reads the profile data of one user. It uses the user ID to find the record.

### Parameters

| Parameter | Type   | Location | Required | Description                  |
|-----------|--------|----------|----------|------------------------------|
| id        | string | path     | yes      | The unique identifier of the user. |

### Request Example

```
read /api/users/42a7f3b9
```

### Response

**Status: 200 OK**

The call returns a JSON object with the user profile.

```json
{
  "id": "42a7f3b9",
  "name": "Jane Doe",
  "email": "jane.doe@example.com",
  "role": "editor",
  "created_at": "2025-03-15T10:30:00Z"
}
```

### Response Fields

| Field      | Type   | Description                   |
|------------|--------|-------------------------------|
| id         | string | The unique identifier.        |
| name       | string | The full name of the user.    |
| email      | string | The email address.            |
| role       | string | The access role of the user.  |
| created_at | string | The ISO 8601 timestamp.       |

### Error Codes

| Code | Meaning            | Cause                                  |
|------|--------------------|----------------------------------------|
| 404  | Not Found          | No user exists with the given ID.      |
| 400  | Bad Request        | The ID format is not valid.            |
| 401  | Unauthorized       | The request does not include a token.  |
| 500  | Internal Error     | A server failure occurred.             |
