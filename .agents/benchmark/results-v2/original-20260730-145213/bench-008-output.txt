## Corrected Text

```
GET /api/users — retrieves all users.
POST /api/users — creates a new user.
PATCH /api/users/:id — partially modifies an existing user.
DELETE /api/users/:id — removes a user.
```

| # | Issue | Severity | Fix Applied |

| 2 | **"fetches" is non-standard** — Common REST documentation convention prefers "retrieves" or "returns" over colloquial "fetches." | LOW | Changed `fetches` → `retrieves` |

The text is otherwise well-formed: consistent route structure, uses path parameters correctly (`:id`), and follows the standard HTTP method → description pattern.
