# STE-Code Compliant API Documentation — User Management Service

## Overview
This document gives the API endpoints for the user management service.
All endpoints use authentication. You must include a valid token in the request header.
All request and response bodies use JSON format.
The base URL is `/api/users`.

---

## Endpoints

### GET /api/users
**Purpose:** Get all users.

**Parameters:**

| Name   | In    | Type    | Mandatory | Description                                |
|--------|-------|---------|-----------|--------------------------------------------|
| page   | query | integer | No        | The page number to get. Default: 1.        |
| limit  | query | integer | No        | The maximum quantity of users per page. Default: 20. Maximum: 100. |

**Request format:** No request body is necessary.

**Response format (200 OK):**

```json
{
  "data": [
    {
      "id": "string",
      "name": "string",
      "email": "string",
      "role": "string",
      "created_at": "string (ISO 8601)"
    }
  ],
  "pagination": {
    "page": 1,
    "limit": 20,
    "total": 150,
    "pages": 8
  }
}
```

**Error codes:**

| Code   | Meaning                                         |
|--------|-------------------------------------------------|
| 401    | Authentication is missing or not valid.         |
| 403    | You do not have permission to do this action.   |
| 500    | An internal server error occurred.              |

---

### POST /api/users
**Purpose:** Make a new user.

**Parameters:** None in the URL.

**Request format:**

```json
{
  "name": "string (mandatory)",
  "email": "string (mandatory, must be unique)",
  "password": "string (mandatory, minimum 8 characters)",
  "role": "string (optional, default: \"user\")"
}
```

**Response format (201 Created):**

```json
{
  "id": "string",
  "name": "string",
  "email": "string",
  "role": "string",
  "created_at": "string (ISO 8601)"
}
```

**Error codes:**

| Code   | Meaning                                                            |
|--------|--------------------------------------------------------------------|
| 400    | The request body is not valid or has missing mandatory fields.     |
| 401    | Authentication is missing or not valid.                            |
| 403    | You do not have permission to do this action.                      |
| 409    | A user with this email already exists.                             |
| 422    | The data is not valid (e.g. password is too short).                |
| 500    | An internal server error occurred.                                 |

---

### GET /api/users/:id
**Purpose:** Get one user by their identifier.

**Parameters:**

| Name | In   | Type   | Mandatory | Description                               |
|------|------|--------|-----------|-------------------------------------------|
| id   | path | string | Yes       | The unique identifier of the user to get. |

**Request format:** No request body is necessary.

**Response format (200 OK):**

```json
{
  "id": "string",
  "name": "string",
  "email": "string",
  "role": "string",
  "created_at": "string (ISO 8601)",
  "updated_at": "string (ISO 8601)"
}
```

**Error codes:**

| Code   | Meaning                                         |
|--------|-------------------------------------------------|
| 401    | Authentication is missing or not valid.         |
| 403    | You do not have permission to do this action.   |
| 404    | No user with this identifier was found.         |
| 500    | An internal server error occurred.              |

---

### PUT /api/users/:id
**Purpose:** Change the data of a user.

**Parameters:**

| Name | In   | Type   | Mandatory | Description                                  |
|------|------|--------|-----------|----------------------------------------------|
| id   | path | string | Yes       | The unique identifier of the user to change. |

**Request format:** Include only the fields you want to change.

```json
{
  "name": "string (optional)",
  "email": "string (optional, must be unique)",
  "password": "string (optional, minimum 8 characters)",
  "role": "string (optional)"
}
```

**Response format (200 OK):**

```json
{
  "id": "string",
  "name": "string",
  "email": "string",
  "role": "string",
  "created_at": "string (ISO 8601)",
  "updated_at": "string (ISO 8601)"
}
```

**Error codes:**

| Code   | Meaning                                                            |
|--------|--------------------------------------------------------------------|
| 400    | The request body is not valid.                                     |
| 401    | Authentication is missing or not valid.                            |
| 403    | You do not have permission to do this action.                      |
| 404    | No user with this identifier was found.                            |
| 409    | A different user already uses this email.                          |
| 422    | The data is not valid.                                             |
| 500    | An internal server error occurred.                                 |

---

### DELETE /api/users/:id
**Purpose:** Remove a user.

**Parameters:**

| Name | In   | Type   | Mandatory | Description                                  |
|------|------|--------|-----------|----------------------------------------------|
| id   | path | string | Yes       | The unique identifier of the user to remove. |

**Request format:** No request body is necessary.

**Response format (204 No Content):** The response body is empty.

**Error codes:**

| Code   | Meaning                                         |
|--------|-------------------------------------------------|
| 401    | Authentication is missing or not valid.         |
| 403    | You do not have permission to do this action.   |
| 404    | No user with this identifier was found.         |
| 500    | An internal server error occurred.              |

---

## Authentication
All endpoints need authentication. Include an HTTP header with each request:

```
Authorization: Bearer <your_token>
```

If the token is not included or is not valid, the server sends the `401 Unauthorized` error.
