# validate-json

## Description

The `validate-json` library validates JSON data against a schema. You can add custom rules for validation. The library includes a command-line interface (CLI) and a programmatic API.

## Installation

Install `validate-json` with npm. Use this command:

```bash
npm install validate-json
```

You can also install it with yarn. Use this command:

```bash
yarn add validate-json
```

## Usage

### CLI

To validate a JSON file against a schema, use this command:

```bash
validate-json --data data.json --schema schema.json
```

The program shows the validation result in the terminal. It shows a list of errors if the data is not valid.

### Programmatic API

Import the library in your code. Use this statement:

```javascript
const { validate } = require('validate-json');
```

Call the `validate` function. Give the function your data and your schema:

```javascript
const result = validate(data, schema);
if (result.valid) {
  console.log('The data is valid.');
} else {
  console.log('Errors:', result.errors);
}
```

### Custom Rules

You can add custom validation rules. First, define a rule. Use a function that accepts a value and a context:

```javascript
const customRule = (value, context) => {
  if (value !== 'expectedValue') {
    return 'The value does not match the expected value.';
  }
  return null;
};
```

Then, register the rule. Use the `registerRule` method:

```javascript
validate.registerRule('customCheck', customRule);
```

Now you can use the rule in your schema. Write the rule name in the schema object:

```json
{
  "myField": { "customCheck": true }
}
```
