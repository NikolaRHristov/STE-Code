## Release v2.0.0

This major release includes a complete API overhaul, removal of deprecated functionality, and significant performance improvements across the application.

### BREAKING CHANGES

- The `UserService.create()` method has been removed. Use `UserService.register()` instead.
- The configuration file format has changed from JSON to YAML. Existing JSON configuration files must be converted to YAML before upgrading. A migration script is available at `tools/json-to-yaml-migrate`.
- Containerize the application using the new `Dockerfile` included in this release. The previous Docker configuration has been deprecated and removed.

### New Features

- WebSocket connection support for real-time client-server communication.
- Redesigned admin dashboard with system health monitoring, user analytics, and activity logs.
- Automated CI/CD deployment pipeline with build verification and staged rollouts.

### Bug Fixes

- Resolved an intermittent crash during session cleanup caused by a race condition in the connection pool.
- Redesigned the login page with improved layout, accessibility, and error feedback.
- Addressed a range of minor issues including memory leaks in the scheduler, incorrect timezone handling in reports, and edge-case validation errors in form inputs.

### Migration Guide

To upgrade from v1.x:

1. Convert your configuration files from JSON to YAML format:
   - Run the migration script: `tools/json-to-yaml-migrate --config /path/to/config.json`
   - Verify the generated YAML files before deleting the originals.
2. Update all `UserService.create()` calls to `UserService.register()`. The method signature remains the same; only the name has changed.
3. Rebuild your Docker containers using the new `Dockerfile`:
   - `docker build -t your-app:v2.0.0 .`
   - `docker-compose up -d`
4. Run your full test suite and smoke-test critical paths in a staging environment before deploying to production.
