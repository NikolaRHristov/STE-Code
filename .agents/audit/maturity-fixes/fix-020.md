## Quality Gates

After each batch, check every generated file against these gates. A batch fails if any gate fails.

| # | Gate | Check |
|---|------|-------|
| 1 | Valid JSON | `python3 -c "import json; json.load(open('FILE'))"` — no parse errors |
| 2 | Traceable source | Each `source` field is `generated-batch-N`. A `proposed` source is acceptable if `approved: false`. No blank or guessed sources. |
| 3 | No invented terms | Each `term` appears in `ste-code/adapted/a-dictionary.md` OR has `"approved": false, "source": "proposed"` |
| 4 | Non-duplicate | Run `python3 .agents/scripts/check-duplicates.py <FILE>` — zero duplicates across batches |
| 5 | Code examples present | Every verb, adjective, and domain entry has both `code_example_ste` and `code_example_non_ste` |
| 6 | Synonym trace | Every entry in `replaces` arrays maps to a row in `SCE/core/categories/synonym-table.json` |
| 7 | Batch size limit | No worker output exceeds 20 entries. Split the worker into two if more entries are needed. |

NOTE: A batch that fails gate 3 (invented terms) or gate 6 (broken synonym trace) must be regenerated from a corrected prompt. A batch that fails gate 4 (duplicates) needs deduplication with `python3 .agents/scripts/deduplicate.py <FILE>`.
