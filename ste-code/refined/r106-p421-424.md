## Dictionary

#### valid (adj) — unapproved

- **Approved alternative:** CORRECT (adj)

> **STE:** MAKE SURE THAT THE TEST RESULTS ARE CORRECT.
> **Non-STE:** Make sure that the test results are valid.

- **Approved alternative:** APPLICABLE (adj)

> **STE:** THIS PROCEDURE IS APPLICABLE ONLY IN DIGITAL MODE.
> **Non-STE:** This procedure is only valid in digital mode.

- **Technical noun:** This word becomes part of a technical noun when it refers to an official document.

> **Example:** NDT PERSONNEL MUST HOLD A VALID CERTIFICATE OF COMPETENCE AT LEVEL 1, 2, OR 3.

> **See:** Dictionary entry for CORRECT (adj); Dictionary entry for APPLICABLE (adj).

#### validity (n) — unapproved

- **Approved alternative:** CORRECT (adj)

> **STE:** MAKE SURE THAT THE TEST RESULTS ARE CORRECT.
> **Non-STE:** Check the validity of the test results.

- **Approved alternative:** APPLICABLE (adj)

> **STE:** THIS STEP IS APPLICABLE ONLY WHEN YOU APPLY THE TOP LAYER OF PAINT.
> **Non-STE:** The validity of this step is restricted to the application of the paint topcoat.

> **See:** Dictionary entry for CORRECT (adj); Dictionary entry for APPLICABLE (adj).

#### VALUE (n) — APPROVED

- **Meaning:** A quantity that is calculated or given
- **Example:**

> **STE:** MAKE SURE THAT THE VALUES AGREE WITH THE SPECIFIED TOLERANCES.

#### vent (v) — unapproved

- **Approved alternative:** RELEASE (v)

> **Non-STE:** Vent the pressure.

- **Approved alternative:** FLOW (v)

> **STE:** MAKE SURE THAT THE TANK IS IN AN OPEN AREA THAT HAS A GOOD AIRFLOW.
> **Non-STE:** Make sure that the tank is in an area that is vented to the atmosphere.

> **See:** Dictionary entry for RELEASE (v); Dictionary entry for FLOW (v); Dictionary entry for OPEN (adj).

- **Approved alternative:** Use a different construction. Tell the reader what the risk or effect is.

> **STE:** BE CAREFUL WITH THE SOLVENT NEAR FLAMES OR SPARKS. THIS SOLVENT CAN RELEASE FLAMMABLE FUMES.
> **Non-STE:** Be careful with the solvent (this solvent is volatile and can be dangerous).
