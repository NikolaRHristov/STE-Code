# Dictionary — R (RELAY through rest)

> **Source:** ASD-STE100 Issue 9, January 2025
> **Pages:** 357–360 of 434

## Approved Words

#### RELEASE (v)

- To make free, to let go
- Forms: RELEASES, RELEASED, RELEASED
- Example: RELEASE THE INSTRUMENT PANEL TO GET ACCESS TO THE CONNECTIONS.

#### THEIR (adj)

- Example: INSTALL THE BOLTS IN THEIR HOLES.
- Non-STE: Install the bolts in the relevant holes.

#### ITS (adj)

- Example: INSTALL THE COMPUTER IN ITS RACK.
- Non-STE: Install the computer in the relevant rack.

#### REMAINING (adj)

- That continues to stay
- Example: REMOVE THE REMAINING SEALANT WITH SOLVENT.

#### REMOVAL (n)

- A procedure which removes an object
- Example: THE SUPERVISOR MUST GIVE THE APPLICABLE PROCEDURE FOR CORROSION REMOVAL.

#### REMOVE (v)

- To take or move something away from its initial position
- Forms: REMOVES, REMOVED, REMOVED
- Example: REMOVE THE INDICATOR FROM THE PANEL.

#### NEW (adj)

- Example: IF THE PAINT ON THE CONTROL BOX IS DAMAGED, APPLY NEW PAINT.

#### REPAIR (n)

- The act of repairing or the result when something is repaired
- Example: AFTER THE REPAIR, APPLY A PROTECTIVE LAYER OF GREASE TO ALL EXTERNAL SURFACES.

#### REPAIR (v)

- To make an item serviceable
- Forms: REPAIRS, REPAIRED, REPAIRED
- Example: REPAIR THE DEFECTIVE WIRING.

#### REPLACE (v)

- To remove an item and to install a new or serviceable item of the same type
- Forms: REPLACES, REPLACED, REPLACED
- Example: REPLACE THE RELAY.

#### REPLACEMENT (n)

- The item you install when you replace an item
- Example: MAKE SURE THAT THE REPLACEMENT HAS THE CORRECT DIMENSIONS.

#### REPORT (n)

- The information that is recorded about a subject or occurrence
- Example: IF THERE IS A REPORT OF DAMAGE, DO AN ACCURATE INSPECTION.

#### RESISTANT (adj)

- That will help to prevent something
- Example: THE MATERIAL OF THE SEATS IS RESISTANT TO FIRE.
