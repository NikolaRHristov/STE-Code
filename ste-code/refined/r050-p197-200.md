## Dictionary Entries

### COMPONENT (n) — APPROVED

- **Meaning:** A part, subassembly, or unit that has a specified function
- **Example:**
  > **STE:** CLEAN THESE COMPONENTS WITH APPROVED SOLVENTS.

### comprehensive (adj) — UNNAPPROVED

- **Approved alternative:** FULL (adj)
- **Examples:**
  > **STE:** DO A FULL INSPECTION OF THE FAIRING.
  >
  > **Non-STE:** Do a comprehensive inspection of the fairing.

### COMPRESS (v) — APPROVED

- **Inflections:** COMPRESSES, COMPRESSED, COMPRESSED
- **Meaning:** To decrease or cause to decrease in dimension or volume
- **Examples:**
  > **STE:** COMPRESS THE SPRING AND CAREFULLY INSTALL THE COVER.
  >
  > **STE:** WHEN THE SPRING COMPRESSES, THE VALVE OPENS.

### comprise (v) — UNNAPPROVED

- **Approved alternative:** HAVE (v)
- **Examples:**
  > **STE:** THE VALVE ASSEMBLY HAS THESE PARTS:
  >
  > **Non-STE:** The valve assembly comprises these parts:

### CONTAIN (v) — APPROVED

- **Examples:**

  >
  > **Non-STE:** Each survival kit comprises these items.

### conclusion (n) — UNNAPPROVED

- **Approved alternatives:**
  - END (n)
  - RESULT (n)

### CONDENSATION (n) — APPROVED

- **Meaning:** The result when a gas changes into a liquid
- **Example:**
  > **STE:** SET THE SWITCH TO THE "ON" POSITION TO REMOVE THE CONDENSATION.

### CONDITION (n) — APPROVED

- **Meanings:**
  1. Something that is necessary for what occurs
  2. The state of an item
- **Examples:**
  > **STE:** THESE INITIAL CONDITIONS ARE NECESSARY TO GET CORRECT RESULTS.
  >
  > **STE:** DO A CHECK OF THE UNIT CONDITION.
- **Note:** Use IF (conj) for "on the condition that."
  > **STE:** IF THERE IS NO WIND, DO THE TEST OUTDOORS.
  >
  > **Non-STE:** On the condition that there is no wind, do the test outdoors.
