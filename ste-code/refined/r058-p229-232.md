# ASD-STE100 Dictionary — E (efficiently–enlarge)

> **Source:** ASD-STE100 Issue 9, January 2025

## Dictionary

#### efficiently (adv) — UNAPPROVED

- Approved alternative: **SATISFACTORILY** (adv)

> **STE:** MAKE SURE THAT THE UNIT OPERATES SATISFACTORILY.
> **Non-STE:** Make sure the unit operates efficiently.

- Approved alternative: **EXHAUST** (n)
