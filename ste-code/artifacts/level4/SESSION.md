# Level 4 Session — Quick Start

## What's Ready
- 51 Level 5 summaries at `ste-code/artifacts/level5/sec*/a-sec*/summary.md`
- Assembly script at `.agents/tools/assemble-level4.py`
- Output dir at `ste-code/artifacts/level4/`
- State tracking via `.agents/state/LEVEL4-PROGRESS.json`

## How to Run

```bash
# Dry run — verify setup
python3 .agents/tools/assemble-level4.py --dry-run

# Launch worker (reads all 51 summaries, assembles ~50K prompt)
python3 .agents/tools/assemble-level4.py
```

## What the Worker Does

1. Reads all 51 Level 5 rule summaries
2. For each rule, extracts compact version (title + 1-sentence requirement + 1 example pair)
3. Reads synonym table from `ste-code/data/synonym-table.json`
4. Reads dictionary excerpt from `ste-code/adapted/a-dictionary.md` (first 200 lines)
5. Assembles everything into `ste-code/artifacts/level4/system-prompt.txt`
6. Target: 40,000–55,000 tokens

## Inputs
| File | Purpose |
|------|---------|
| `ste-code/artifacts/level5/*/summary.md` | 51 rule summaries (compact source) |
| `ste-code/data/synonym-table.json` | Complete synonym pairs |
| `ste-code/adapted/a-dictionary.md` | Dictionary excerpt (lines 1-200) |

## Output
- `ste-code/artifacts/level4/system-prompt.txt` — Level 4 prompt (~50K tokens)

## After Level 4
Level 3, 2, 1, 0, -1, -2 can be generated by further compressing Level 4 output.
