### A

**A (art)** — Indefinite article. A CONFIG FILE IS INCLUDED IN THE ROOT DIRECTORY. Unapproved: omission of article.

**ABOUT (prep)** — Concerned with (a subject). FOR DATA ABOUT THE CONFIGURATION OF THE MODULE, REFER TO THE README. Unapproved: "regarding" (in place of "about" as subject), "about" to mean "approximately."

**ABOVE (prep)** — In a position higher than something. MOVE THE CURSOR ABOVE THE TARGET LINE. Unapproved: "above" to mean "more than" (use MORE THAN).

**ABRASIVE (adj)** — That can remove material by friction (domain-specific; no code equivalent). No code-domain example. Unapproved: none (retained for completeness).

**ABSORB (v)** — To take up or consume; to decrease the effect of. THE CACHE LAYER ABSORBS THE LOAD FROM REPEATED QUERIES. Unapproved: "mitigate," "take up."

**ACCEPT (v)** — To make a decision that something is satisfactory. ACCEPT THE PULL REQUEST IF IT PASSES ALL CHECKS. Unapproved: "merge" (for acceptance decision).

**ACCESS (n)** — The ability to read, write, or enter. GET ACCESS TO THE REPOSITORY FOR THE AUTHENTICATION MODULE. Unapproved: "access" as a verb.

**ACCIDENT (n)** — An occurrence that causes harm or data loss. TO PREVENT ACCIDENTS, MAKE SURE THAT THE BACKUPS ARE CONFIGURED. Unapproved: none.

**ACCIDENTAL (adj)** — That does not occur on purpose. TO PREVENT ACCIDENTAL DELETION OF THE FILES, CONFIRM THE OPERATION. Unapproved: "inadvertent."

**ACCIDENTALLY (adv)** — That does not occur on purpose. IF YOU ACCIDENTALLY PRESS THE DELETE KEY, RESTORE THE FILE FROM THE RECYCLE BIN. Unapproved: "inadvertently."

**ACCURATE (adj) / ACCURATELY (adv)** — Exact; with precision. THE MEASUREMENT MUST BE ACCURATE. / APPLY THE PATCH ACCURATELY ON THE TARGET BRANCH. Unapproved: "precise" / "precisely."

**ACROSS (prep)** — From one side to the other side; spanning boundaries. SEARCH ACROSS ALL MODULES FOR THE DEPRECATED FUNCTION. Unapproved: omission of "across" (bare "search all modules").

**ACTIVATE (v)** — To make a system, function, or feature ready for operation. THE BUILD PIPELINE ACTIVATES THE DEPLOYMENT MODE. Unapproved: "trigger" (for making ready), "activate" for "start."

**ACTIVE (adj)** — A system, function, or feature in a state of action. READ THE CONFIG FROM THE ACTIVE BRANCH. Unapproved: "current."

**ADAPT (v)** — To change or adjust to that which is necessary. THE MIDDLEWARE LAYER ADAPTS TO THE PROTOCOL OF THE CONNECTED SERVICES. Unapproved: "adjust" to fit, "conform."

**ADD (v)** — To increase the number, dimension, or quantity. ADD 5 LINES OF CONFIGURATION TO THE FILE. Unapproved: "append."

**ADJACENT (adj) / ADJACENT TO (prep)** — Near to an element with no other element of the same type between. DO NOT MODIFY THE ADJACENT FUNCTION. / THE CONFIG FILE IS LOCATED ADJACENT TO THE MAIN MODULE. Unapproved: "next to," "that is next to it."

**ADJUST (v)** — To put in or come to a specified position or value. ADJUST THE TIMEOUT TO THE VALUE GIVEN IN TABLE 1. Unapproved: "tune."

**ADJUSTABLE (adj) / ADJUSTMENT (n)** — That you can adjust; the effect of adjusting. THE TWO PARAMETERS ARE ADJUSTABLE. / MAKE SURE THAT THE ADJUSTMENT IS IN THE LIMITS GIVEN IN TABLE 1. Unapproved: "tunable" / "tuning."

**AFT (adj) / AFT (adv)** — At or nearer to the rear of a vehicle (domain-specific aerospace; no code equivalent). No code-domain example. Unapproved: none (retained for completeness).

**AFTER (conj)** — That follows a specified time, sequence, or operation. AFTER YOU DEPLOY THE UPDATE, DO A SMOKE TEST. Unapproved: "following" + gerund ("following deployment of").

**AGAIN (adv)** — One more time. RUN THE TEST AGAIN. Unapproved: "rerun" (prefix form).

### B

**BACK (adj) / BACK (adv)** — In a direction opposite to forward. REVERT TO THE BACK VERSION. / NAVIGATE BACK TO THE PREVIOUS PAGE. Unapproved: "previous" (for adj), "backwards."
