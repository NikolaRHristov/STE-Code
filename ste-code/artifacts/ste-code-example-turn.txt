## STE-CODE OUTPUT

```
/**
 * This middleware authenticates incoming API requests.
 *
 * It extracts the bearer token from the authorization header.
 * Then, it validates the token. If the token is not valid or is
 * missing, the middleware sends a 401 error.
 *
 * IMPORTANT: Call this middleware before route handlers that
 * require authentication.
 *
 * Set the JWT_SECRET environment variable before you use this
 * middleware.
 *
 * How it works:
 * - Uses the jsonwebtoken library to check the token signature.
 * - Attaches the decoded user object to the request.
 * - Records each authentication attempt in the log.
 *
 * @param {Request} req — The HTTP request.
 * @param {Response} res — The HTTP response.
 * @param {Function} next — The function to call the next middleware.
 *
 * DEPRECATED: Use authMiddlewareV2. Version 2 supports key rotation
 * and multi-tenant deployments.
 */
```
