# STE-Code — Consolidated Standard (final/)


STE-Code is a controlled-language variation of ASD-STE100 for software documentation. This `final/` directory consolidates every pipeline stage.


## Contents

- `rules/` — 54 enriched adapted rules + categories + dictionary (Phases D+G)

- `extensions/` — 6 code-domain vocabulary files (Phase E)

- `reference-catalogue.md` — vendor/community references (kept in .agents/reference/)

- `provenance.md` — stage-by-stage audit trail


## Use

Load `rules/` as the canonical rule set; `extensions/` as the approved vocabulary; consult `reference-catalogue.md` for external authority.
